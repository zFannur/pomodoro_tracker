# Changelog

Все заметные изменения проекта. Формат основан на
[Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [SemVer](https://semver.org/lang/ru/).

## [1.3.1] — 2026-07-27

Разбор дефектов синхронизации по трём симптомам с реального использования:
на Android приложение зависало до прохождения авторизации, диалог входа
показывался несколько раз подряд, закрытые на телефоне задачи не появлялись
на ПК, а идущий помидор не был виден на втором устройстве. Найдено и
исправлено 23 дефекта — подробный разбор каждого в [BUGS.md](BUGS.md).

### Исправлено

- **Данные с другого устройства больше не пропадают.** Правка, сделанная в
  окне между применением удалённой версии и перечитыванием состояния,
  помечала приехавшие записи как удалённые — и они исчезали у всех навсегда.
- **Синк перестал молча выключаться.** Одной неудачной тихой авторизации
  хватало, чтобы отправка правок отключилась до перезапуска приложения:
  телефон копил изменения и не отправлял их никогда.
- **`data.json` больше не может стать битым.** Запись документа и приём
  удалённой версии шли через один временный файл без взаимного исключения.
- **Чёрный экран на старте Android.** Звуки пересинтезировались на каждом
  запуске до первого кадра, следом шла ещё цепочка блокирующих операций.
- **Диалог входа Google больше не показывается по кругу.** Его собственное
  появление запускало новый синк, который открывал следующий диалог.
- **Таймер считает по настенным часам.** После сна машины помидор «на 25
  минут» реально длился сорок пять.
- **Помидор, дотикавший при закрытом приложении, попадает в журнал**, а не
  выбрасывается молча. Овертайм Flowtime переживает перезапуск.
- Восстановленная из корзины задача больше не исчезает после синхронизации.
- Ночные помидоры (после полуночи) остаются в конце своего дня после слияния.
- Веха спринта не пропадает, если на втором устройстве она пустая.
- Сброс 🐸/⭐ при смене дня и недели делает одно устройство, а не каждое:
  отметки переехали в синхронизируемый документ.
- Настройки пишутся атомарно — прерванная запись больше не сбрасывает их
  в значения по умолчанию вместе с ключами синхронизации.
- Правки журнала сразу обновляют статистику и спринт.

### Добавлено

- **Помидор виден на втором устройстве.** Идущий или приостановленный
  помидор показывается с подписью «идёт на другом устройстве», отсчёт идёт
  по настенным часам. Запись в журнал делает только то устройство, где он
  запущен, — двойных записей не будет. Снимок отправляется на переходах
  (старт, пауза, стоп, смена фазы), а не каждые 15 секунд.

### Изменено

- Зеркала в валт по умолчанию включены только там, где валт есть (Windows).
  На Android они писались в приватный каталог приложения — файловая операция
  на каждый день истории при каждой синхронизации, без пользы.

## [1.3.0] — 2026-07-20

### Добавлено

- **Синхронизация Google Drive** — `data.json` в скрытой папке приложения
  (appDataFolder): задачи, журнал и спринты одним документом. Автосинк при
  старте, возврате в приложение и через 5 секунд после правок. Windows входит
  через браузер (Desktop-клиент), Android — через google_sign_in. Настройка:
  Настройки → Приложение → Google Drive, инструкция по Cloud Console — в README.
- **Слияние вместо выбора победителя** — при правках на обоих устройствах
  списки объединяются по id: ни задача, ни помидор не пропадают. Более свежая
  сторона решает только спорные скаляры (цель дня, веха недели); проигравшая
  версия дополнительно сохраняется в `data_conflict.json`.
- **Надгробия удалённых записей** — удаления записываются явно и едут вместе
  с данными, поэтому больше не воскресают при повторном подключении или
  слиянии двух устройств. Ставятся диффом при записи файла, то есть покрывают
  разом все пути удаления. Удаление побеждает безусловно, без сравнения часов.
- **Android-версия** — адаптивный интерфейс: навигация снизу на узких экранах,
  AppBar с шестерёнкой, поле ввода и управление в две строки; сборка APK,
  иконка приложения. Таймер живёт, пока приложение открыто.
- **Группа «Сделано сегодня»** на экране «Задачи» — записи журнала за день.
- **Корзина задач** — любое удаление (⋮-меню, «минус» в ноль, «Очистить
  список», планировщик) кладёт задачу в группу «Корзина» на экране «Задачи»;
  восстановление одним кликом. Последние 30 удалений, живёт до перезапуска.

### Изменено

- **`Журнал/*.md` и `Спринты/*.md` стали зеркалами**, как `Задачи.md`: правки
  в них больше не читаются и затираются. Это цена синхронизации журнала —
  истина переехала в `data.json`. Существующая история мигрирует при первом
  запуске; исходные файлы не удаляются.
- У записей журнала появились стабильные идентификаторы.

### Исправлено

- **Отметка «сделано» теряла задачу из виду**: запись уходила в журнал, но ни
  журнал, ни статистика не перечитывались, а показать выполненное на экране
  «Задачи» было негде — задача просто исчезала.
- **Правка и удаление записи журнала попадали не в ту строку**: два помидора
  одной минуты по одной задаче были неразличимы.
- «Очистить список» удалял задачи «Сегодня» безвозвратно и без честного
  предупреждения — теперь всё уезжает в корзину и возвращается.
- Запись файла сериализована: медленная ранняя запись больше не может
  финишировать позже и затереть более свежую.
- Синк и репозиторий писали через один временный файл — пересечение давало
  склейку контента и битый JSON.
- Правка, попавшая между чтением файла и отправкой, помечалась как
  отправленная и не уезжала уже никогда.
- Отложенная отправка, попавшая в уже идущий синк, молча терялась без повтора.
- Вход Google: `initialize()` вызывался повторно при смене Server Client ID
  (пакет этого не допускает), а неудачная инициализация кешировалась и ломала
  все следующие попытки до перезапуска.
- Нажатие «Подключить» показывало окно входа дважды подряд.
- Поле настроек отдавало значение только при потере фокуса — введённый
  Server Client ID не успевал сохраниться до нажатия кнопки.
- Экран статистики не отрисовывался: растягивание в ряду плиток внутри
  прокручиваемой колонки давало бесконечную высоту.
- График по дням мог переполнять колонку при крупном системном шрифте:
  высота столбика считалась от угаданного запаса под подписи.
- На Android больше не показываются кнопки, зовущие Windows-плагины
  (полноэкранный режим, выбор папки хранения).

## [1.2.0] — 2026-07-18

### Добавлено

- **Экран «Задачи»** — полноэкранный задачник (вторая вкладка): quick-add
  с умным вводом (Enter — во «Входящие», Ctrl+Enter — в «Сегодня», Ctrl+N —
  фокус из любого места), сворачиваемые группы со счётчиками (состояние
  запоминается), подсветка СЕЙЧАС у первой задачи, drag-сортировка внутри
  корзин планировщика, undo-снекбар на удаление, адаптивная вёрстка
  (два столбца ≥1000px / один столбец).
- **Хранилище задач `tasks.json`** (AppData, атомарная запись, стабильные
  id) — задачник больше не зависит от валта; при первом запуске задачи
  мигрируют из `Задачи.md` автоматически.
- **`Задачи.md` — одностороннее зеркало** для просмотра в Obsidian
  (переключатель в настройках); правки в нём не читаются.
- **`Входящие.md` — файл-инбокс**: строки из него забираются во «Входящие»
  при запуске и фокусе окна (захват задач из Obsidian и с телефона).
- **Категории в диалоге редактирования** — выпадающий список + свободный
  ввод новой; новая категория сразу регистрируется в настройках. Диалог
  общий для задач и записей «Сделано» (с полем минут).
- **Один экземпляр на систему** — повторный запуск поднимает открытое окно.

### Исправлено

- Пробел (и другие хоткеи) при наборе текста дёргали таймер: проверка
  «фокус в поле ввода» не работала ни для одного поля — EditableText теперь
  ищется вверх по дереву от точки фокуса.
- Два одновременно запущенных экземпляра молча перезаписывали задачи друг
  друга (воскрешение удалённых) — закрыто single-instance guard'ом.
- Ввод «#категория ~3» без описания молча стирал набранный текст.
- Undo удаления мог вернуть вторую 🐸 — инвариант «одна лягушка» побеждает.
- Пустая категория при редактировании больше не затирает старую.

## [1.1.0] — 2026-07-17

### Добавлено

- **Локализация интерфейса** — Русский / English, переключается в настройках
  мгновенно, без перезапуска приложения; данные в markdown-валте (названия
  файлов, секции, категории) языком не затрагиваются.
- **Тема «Матрица»** — чёрный фон, неоновый зелёный, моноширинный шрифт;
  добавлена к существующим Светлой / Тёмной / Системной / Авто.
- `README.en.md` — англоязычная документация, зеркало `README.md`.

### Исправлено

- Диалоги настроек и планировщика резолвили кубиты **лениво** внутри
  `builder`, используя внешний `context` — при перестройке экрана за диалогом
  это могло уронить `ProviderNotFoundException`. Кубиты теперь резолвятся
  сразу при открытии.
- Строка «Цветовая схема» в настройках переносилась по одной букве при
  пятой теме — переверстана в колонку.

### Изменено

- Из README и CHANGELOG убраны упоминания «клона» другого сайта — проект
  описан на своих условиях, без отсылок к конкретному прототипу.

## [1.0.0] — 2026-07-16

Первый релиз.

### Добавлено

**Таймер по технике Pomodoro** с точной моделью серий, простоев и фокуса:

- таймер помидор/короткий/длинный перерыв со схемами (`classic` 25/5/15×4,
  `work` 50/10/20×2, `personal` 30/2/25×4), автостарты, продление фазы;
- логический день 05:00–05:00; оценка задач в минутах; верхняя задача — текущая;
- учёт простоя и прерываний, формула фокуса, сгорание серии при долгом простое,
  анти-накрутка ручных записей;
- умный ввод `#категория Описание ~N`, разбиение и слияние задач,
  прогноз времени окончания с учётом перерывов;
- планировщик по срокам (Входящие / Завтра / Эта неделя / Позже),
  просроченное автоматически возвращается во «Входящие»;
- 10 финишных мелодий (синтезируются в WAV), тиканье, системные уведомления,
  кастомные тексты, дублирование в Telegram;
- темы Светлая / Тёмная / Системная / Авто, 6 форматов даты, 12/24ч;
- восстановление состояния таймера после перезапуска (окно 1 час).

**Система фокуса** (адаптация под личный метод):

- 🐸 лягушка дня — одна, наверху, сбрасывается каждое утро;
- ⭐ задачи спринта — снимаются в новую неделю, закрытые уходят
  в «Сделано за неделю»;
- карточка «СЕЙЧАС» (WIP = 1), Flowtime-овертайм, заметка «на чём встал»,
  подсказка при застревании, предупреждение о перегрузе дня;
- мягкая стата лягушек «N / M активных дней» — намеренно без стрика.

**Хранение** — markdown в Obsidian-валте: `Задачи.md`, `Журнал/YYYY-MM/*.md`,
`Спринты/YYYY-Wnn.md`. Настройки — JSON в `%APPDATA%`.

**Экраны** — Таймер, Спринт (веха, цель, темп, прогноз, график по дням,
история недель), Статистика (периоды, категории, 14 дней, карта активности).

### Дизайн

- Тёплая «бумажная» тема: тонированный фон, карточки с обводкой вместо теней.
- Герой-карточка таймера с градиентом и цветовым кодированием фазы
  (работа — томатный, перерыв — зелёный) и прогресс-баром.
- Кастомные 3D-иконки навигации и логотип; многоразмерный `.ico` (16–256).
- Настройки — внизу NavigationRail; подтверждения необратимых очисток.

### Исправлено

Аудит перед релизом (баги найдены и устранены до первого релиза):

- запись помидора стирала заметки дня из markdown-файла;
- запись и подсчёт шли по разным логическим дням при пересечении 05:00;
- горячие клавиши срабатывали при открытых диалогах (Esc стопал помидор);
- операции применялись к устаревшим индексам задач (меню/диалоги) и к
  Equatable-дубликатам после «Разбить»;
- недоступный Telegram подвешивал завершение помидора (нет таймаута);
- гонка при сбросе 🐸/⭐, преждевременное создание файла спринта в ночь на пн;
- смена папки хранения записывала старые данные в новый валт;
- `|` в тексте задачи необратимо портился при round-trip;
- запись файлов сделана атомарной (temp + rename).
