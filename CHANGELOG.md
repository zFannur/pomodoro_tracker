# Changelog

Все заметные изменения проекта. Формат основан на
[Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [SemVer](https://semver.org/lang/ru/).

## [1.1.0] — 2026-07-17

### Добавлено

- **Локализация интерфейса** — Русский / English, переключается в настройках
  мгновенно, без перезапуска приложения; данные в markdown-валте (названия
  файлов, секции, категории) языком не затрагиваются.
- **Тема «Матрица»** — чёрный фон, неоновый зелёный, моноширинный шрифт;
  добавлена к существующим Светлой / Тёмной / Системной / Авто.
- `README.en.md` — англоязычная документация, зеркало `README.md`.

### Исправлено

- Диалоги настроек и планировщика резолвили кубиты **лениво** внутри
  `builder`, используя внешний `context` — при перестройке экрана за диалогом
  это могло уронить `ProviderNotFoundException`. Кубиты теперь резолвятся
  сразу при открытии.
- Строка «Цветовая схема» в настройках переносилась по одной букве при
  пятой теме — переверстана в колонку.

### Изменено

- Из README и CHANGELOG убраны упоминания «клона» другого сайта — проект
  описан на своих условиях, без отсылок к конкретному прототипу.

## [1.0.0] — 2026-07-16

Первый релиз.

### Добавлено

**Таймер по технике Pomodoro** с точной моделью серий, простоев и фокуса:

- таймер помидор/короткий/длинный перерыв со схемами (`classic` 25/5/15×4,
  `work` 50/10/20×2, `personal` 30/2/25×4), автостарты, продление фазы;
- логический день 05:00–05:00; оценка задач в минутах; верхняя задача — текущая;
- учёт простоя и прерываний, формула фокуса, сгорание серии при долгом простое,
  анти-накрутка ручных записей;
- умный ввод `#категория Описание ~N`, разбиение и слияние задач,
  прогноз времени окончания с учётом перерывов;
- планировщик по срокам (Входящие / Завтра / Эта неделя / Позже),
  просроченное автоматически возвращается во «Входящие»;
- 10 финишных мелодий (синтезируются в WAV), тиканье, системные уведомления,
  кастомные тексты, дублирование в Telegram;
- темы Светлая / Тёмная / Системная / Авто, 6 форматов даты, 12/24ч;
- восстановление состояния таймера после перезапуска (окно 1 час).

**Система фокуса** (адаптация под личный метод):

- 🐸 лягушка дня — одна, наверху, сбрасывается каждое утро;
- ⭐ задачи спринта — снимаются в новую неделю, закрытые уходят
  в «Сделано за неделю»;
- карточка «СЕЙЧАС» (WIP = 1), Flowtime-овертайм, заметка «на чём встал»,
  подсказка при застревании, предупреждение о перегрузе дня;
- мягкая стата лягушек «N / M активных дней» — намеренно без стрика.

**Хранение** — markdown в Obsidian-валте: `Задачи.md`, `Журнал/YYYY-MM/*.md`,
`Спринты/YYYY-Wnn.md`. Настройки — JSON в `%APPDATA%`.

**Экраны** — Таймер, Спринт (веха, цель, темп, прогноз, график по дням,
история недель), Статистика (периоды, категории, 14 дней, карта активности).

### Дизайн

- Тёплая «бумажная» тема: тонированный фон, карточки с обводкой вместо теней.
- Герой-карточка таймера с градиентом и цветовым кодированием фазы
  (работа — томатный, перерыв — зелёный) и прогресс-баром.
- Кастомные 3D-иконки навигации и логотип; многоразмерный `.ico` (16–256).
- Настройки — внизу NavigationRail; подтверждения необратимых очисток.

### Исправлено

Аудит перед релизом (баги найдены и устранены до первого релиза):

- запись помидора стирала заметки дня из markdown-файла;
- запись и подсчёт шли по разным логическим дням при пересечении 05:00;
- горячие клавиши срабатывали при открытых диалогах (Esc стопал помидор);
- операции применялись к устаревшим индексам задач (меню/диалоги) и к
  Equatable-дубликатам после «Разбить»;
- недоступный Telegram подвешивал завершение помидора (нет таймаута);
- гонка при сбросе 🐸/⭐, преждевременное создание файла спринта в ночь на пн;
- смена папки хранения записывала старые данные в новый валт;
- `|` в тексте задачи необратимо портился при round-trip;
- запись файлов сделана атомарной (temp + rename).
