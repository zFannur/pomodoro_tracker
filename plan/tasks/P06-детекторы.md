## 1. Переносы (TasksCubit)

`deferrals + 1` и колбэк `Future<void> Function(PomoTask task)? onDeferred` (после
сохранения, с обновлённой задачей) — ровно в двух случаях:
- `postpone(index, tab)` — задача уходит из «Сегодня» в планировщик;
- `plannerMove(index, tab)` — старая корзина задачи `PlannerTab.due` (срок наступил),
  новая — не `due`.

Не считать: разбор «Входящих» по корзинам, перенос вперёд задачи, чей срок ещё не
наступил, `plannerToToday`. Параметр `bool countDeferral = true` у `postpone` — для
способа `value` («Во „Входящие“» — осознанное решение, P07 передаёт `false`).

Main: `tasksCubit.onDeferred = (t) async { final e = await insightCubit.addEpisode(source: defer, task: t); insightCubit.reportDeferral(e, t.deferrals); }`.

## 2. 🐸 не тронута за день (rollover)

В `rolloverCheck` ПЕРЕД `tasksCubit.clearFrogs()` при `newDay`: взять 🐸-задачу из
`todo` (если есть) и день `marks.day` (последний обработанный день, не буквально
«вчера» — приложение могли не открывать несколько дней). Если в журнале того дня
нет сессии с `taskId == frog.id` — `deferrals + 1` у задачи (новый метод
`TasksCubit.bumpDeferral(String taskId)`) и эпизод `source: frog` с
`at = 23:59 того дня` (логический день тот же). `marks.day == null` (первый запуск) — ничего.

## 3. Простой и напоминания «когда» — `lib/services/nudge_service.dart`

Один `Timer.periodic(30 с)`, запускается из `main` после bootstrap. Решения —
чистыми функциями (их и тестировать), сервис только вызывает их и шлёт уведомления.

```dart
bool shouldNudgeIdle({
  required bool enabled, required bool stoppedPomodoro, required bool foreign,
  required bool hasTodos, required int delayMs, required int? inputIdleSeconds,
  required bool inWindow, required bool alreadyNudged,
});
// true, если: enabled, stoppedPomodoro (mode pomodoro && stopped), !foreign, hasTodos,
// delayMs >= 15 мин, inputIdleSeconds != null && <= 60 (человек за компьютером;
// null на Android → false), inWindow (окна не заданы → true), !alreadyNudged.
```
`alreadyNudged` сбрасывается, когда `delayMs` уменьшился (таймер стартовал).
Срабатывание: тихий эпизод `source: idle` (через `addEpisode`, задача — `tasks.current`)
и `notify.event(title: S.nudgeIdleTitle, body: S.nudgeIdleBody(task))`, `raise: false`.
Тексты: «15 минут без помидора» / «Что мешает начать «{задача}»?».

Публичный геттер в `ActivityTracker`: `int? inputIdleSeconds()` (сейчас приватная
логика «секунд с последнего ввода»; на не-Windows — null).

```dart
List<PomoTask> dueCues(List<PomoTask> todo, DateTime now, Set<String> fired);
// задачи с cueAt == HH:mm(now) и ключом '${id}@${dateKey(logicalDate(now))}' не в fired.
```
Срабатывание: `notify.event(title: S.cueTitle («Пора»), body: «Когда {cue} → {firstStep или описание}»)`,
ключ в `fired` (в памяти; повтор после перезапуска в ту же минуту допустим).

## 4. Отвлечение во время помидора — ActivityTracker

В тике записи (`_record` или где копятся `focusSegments`), когда `inPomodoro()`:
серия секунд подряд в окне, чей ключ в `distracting` (разрыв > 2 тиков или другое
окно — сброс). Серия ≥ 60 с и в этом помидоре ещё не было срабатывания →
`void Function(String label)? onDistraction` (label — как в списке Активности; вынеси
форматтер, если он ещё не общий). Флаг «было срабатывание» сбрасывается, когда
`inPomodoro()` становится false.

Main: `onDistraction = (label) { insightCubit.addEpisode(source: distract, task: tasks.current, app: label); if (settings.nudgeDistraction) notify.event(title: S.nudgeDistractTitle(label) «{label} во время помидора», body: S.nudgeDistractBody «Вернуться к „{задача}“?»); }`.

**Решение при реализации:** `InsightCubit.addEpisode` получил необязательный `at`
для 🐸 в 23:59 последнего обработанного дня. Проверка вынесена в
`services/frog_rollover.dart`; повторный эпизод той же 🐸 за тот же день подавляется.
`bumpDeferral` возвращает обновлённую задачу или null при отсутствии/ошибке записи,
не вызывает `onDeferred`. `_persist` возвращает успех: колбэк переноса не вызывается
при ошибке сохранения. Локальные одновременные rollover объединяются одним Future.

`TimerCubit.start()` сохраняет накопленный `delaysMs`, а не уменьшает его, поэтому
NudgeService сбрасывает защиту также по переходу в running (подписка ловит быстрый
старт/стоп между опросами). Трекер аналогично слушает переходы помидора, чтобы
не пропустить короткий стоп; чужой таймер не считается локальным помидором.
Общий `formatActivityName` перенесён в сервис и переэкспортирован экраном для
совместимости. Неизвестный ввод/ошибка WinAPI — null, без сигнала простоя.
Напоминания «когда» используют существующий NotifyService: системных уведомлений
Android в нём по-прежнему нет; новая зависимость не добавлялась.
