## 1. Сущности — новый файл `lib/domain/entities/episode.dart`

```dart
/// Откуда пришёл сигнал.
enum EpisodeSource { idle, stop, defer, frog, distract, manual }
//  idle — простой при задачах в плане; stop — ранний стоп помидора;
//  defer — перенос задачи со наступившим сроком; frog — 🐸 не тронута за день;
//  distract — отвлекающее окно во время помидора; manual — кнопка «Не идёт».

enum Cause { unclear, big, boring, perfect, tired, pointless, external }

enum StrategyKind { firstStep, warmup, ifThen, shrink, thought, defuse, value, rest, removeCue }

class Episode extends Equatable {
  final String id;
  final DateTime at;            // момент сигнала
  final EpisodeSource source;
  final String taskId;          // '' — без задачи
  final String task;            // снимок описания: задача может исчезнуть
  final String category;
  final Cause? cause;           // null — сигнал без ответа
  final StrategyKind? strategy; // выбранный способ
  final String thought;         // мысль (шаг 1 листа)
  final String fact;            // «что я знаю наверняка» (способ thought)
  final String alt;             // «как сказать точнее»
  final String app;             // окно для distract
}
```

## 2. JSON (`_Doc.encode/decode`, `_dayFrom`)

День:
```jsonc
"e":  [{"id","t":"HH:mm","src":"idle","tid","d","c","cause","st","th","fact","alt","app"}],
"ck": {"sl":4,"en":3,"md":4},
"ips": [3,4,2,3,3,2,4,3,3]
```
`t` — как у сессий (дата берётся из ключа дня, часы 0–4 — следующие календарные сутки,
повтори логику `_sessionFrom`). Enum — по `name`. Неизвестное значение enum →
поле null (не падать: версия на телефоне может быть старше).

Спринт: `"exp": {"h","st","m","base","v"}`, `"ai": {"at","summary","p":[{"t","e"}]}`.

`_Doc.ids()` — добавь id эпизодов (иначе удаление не создаст надгробие).

```dart
abstract interface class InsightRepository {
  Future<Either<Failure, Unit>> addEpisode(Episode e);      // день = logicalDate(e.at)

```
Каждый метод: `_guard` → `_load` → `before = doc.ids()` → правка → `_write(doc, before:)` →
зеркало дня/спринта. Как `addSession`. Спринта с таким id нет в документе — создать
так же, как это делает `current()` (посмотри, как он синтезирует спринт).

**`saveDay` и `saveSprint`:** при записи брать `episodes/checkIn/ips` и
`experiment/review` из хранимого документа, а не из аргумента. Это ловушка №1 из P00:
JournalCubit и SprintCubit держат старые снимки и иначе затрут свежий эпизод.
Чтение (`day`, `range`, `current`) отдаёт новые поля как есть.
