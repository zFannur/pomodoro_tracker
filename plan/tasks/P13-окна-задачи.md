## Часть A — что было открыто во время задачи

### A1. Чистые функции (`activity_tracker.dart`)

```dart
/// Окна всех помидоров [sessions], сложенные по app+title, по убыванию.
List<ActivityRow> segmentsForSessions(
  Map<String, List<ActivitySegment>> byDay,
  Iterable<PomoSession> sessions,
);
```
Для каждой сессии — то же окно, что в `ActivityCubit.segmentsFor` (start − 1 мин …
start + minutes + 1 мин, день `dateKey(logicalDate(start))`), результаты сложить по ключу.
`ActivityCubit.segmentsFor` переписать через неё (одна сессия) — логику окна держать в
одном месте.

В `lib/domain/insights.dart`:
```dart
/// Помидоры задачи: по taskId; у старых записей (до P01) taskId пуст —
/// тогда совпадение описания И категории.
List<PomoSession> sessionsOfTask(List<DayLog> days, {required String taskId,
    required String description, required String category});
```

### A2. Один диалог окон — `lib/presentation/widgets/windows_dialog.dart`

Содержимое (ширина 520, на узком — во весь экран):

## Часть B — что было открыто вместо задачи (простой)

Сейчас трекер пишет отрезки только во время помидора (`focusSegments`). Чтобы видеть,
чем был занят простой, нужны отрезки и вне помидоров.

### B1. Трекер

- `ActivityData.idleSegments` — та же структура, JSON-ключ `"idle"`, отдельно от
  `"segments"` (старый файл читается, ключ `idle` не превращается в день — проверь,
  как `fromJson` пропускает служебные ключи).
- В `_record`: не в помидоре → `addSegmentTick` в `idleSegments`.
- Хранить 14 дней: `pruneDays(data.idleSegments, today, keep: 14)` — добавь параметр
  `keep` в `pruneDays`, если его нет. Обоснование: это самый объёмный ряд, а
  «что было вместо» нужно для недельного разбора, не для архива.
- Удаление истории (`deleteItems` и т. п.) чистит и `idleSegments`.
- Измерь: сгенерируй в тесте день из 8 часов с переключением окна каждые 30 с и
  проверь, что JSON дня `idle` < 300 КБ. Не влезает — сообщи, не оптимизируй молча.

### B2. Окно «вместо» для эпизода

```dart
/// Отрезок времени, когда задача «не шла»: от [e.at] − 15 мин до старта ближайшего
/// помидора после эпизода, но не дольше 60 мин после [e.at].
({DateTime from, DateTime to})? insteadWindow(Episode e, List<PomoSession> daySessions);
```
Только для `idle`, `manual`, `defer`; для остальных — null. Окна — `segmentsSummary`
по `idleSegments`.

### B3. Где показывать

- Разбор → Эпизоды: в меню строки эпизода `idle`/`manual`/`defer` — «Что было вместо»
  → `showWindowsDialog(title: задача, subtitle: «10:00–10:47, до первого помидора»)`.
  У `distract` — «Что было открыто» (окна помидора, внутри которого эпизод).
- Разбор → Неделя (только Windows): секция «Вместо задач» после «Причин» — топ-5 окон
  по сумме `insteadWindow` всех эпизодов недели: «YouTube 1 ч 10 мин · Telegram 25 мин».
  Нет данных — секции нет.
- В ИИ (P11) имена окон не отправляются — не трогать `reviewPayload`.

<tests>
- `segmentsForSessions`: две сессии в разные дни складываются; пересечение окна;
- `segmentsFor` после рефакторинга даёт то же, что раньше (существующие тесты зелёные);
- `sessionsOfTask`: по taskId; старые без taskId — по описанию и категории; чужая категория не берётся;
- `idleSegments`: пишутся вне помидора, не пишутся в помидоре; round-trip JSON; старый
  файл без `idle`; `pruneDays(keep: 14)`; удаление истории чистит; размер дня < 300 КБ;
- `insteadWindow`: ближайший помидор через 20 мин → 15+20 мин; помидора нет → 60 мин;
  `stop` → null;
- виджет: диалог с флажком вызывает `toggleDistracting`; «Ещё N»; пустое состояние;
  пункта «Окна задачи» нет при `Platform.isWindows == false` (флаг через параметр для теста).
</tests>

**Решение при реализации (часть A):** `segmentsForSessions` лежит в `activity_tracker.dart`, `ActivityCubit.segmentsFor` вызывает её с одной сессией, плюс `segmentsForAll` для набора. Окна двух подряд идущих помидоров с паузой < 2 мин могут пересечься и посчитать общий отрезок дважды — окно не обрезается, как и требовало «то же окно». `sessionsOfTask` не берёт ручные отметки (`manual`): таймер их не вёл, окон у них нет, а счётчик «N помидоров» они бы завышали; если у задачи или записи `taskId` пуст — совпадение по описанию И категории; результат отсортирован по старту. Диалог — `widgets/windows_dialog.dart`: `showWindowsDialog` (по спецификации), `showTaskWindowsDialog` (сессии из `InsightCubit.state.days`; без кубита — пустое состояние), `hasWindowsTracker(context, {isWindows})` и `windowsSubtitle`. Кубит берётся до `showDialog` и подаётся в `BlocBuilder(bloc:)`: маршрут диалога не видит провайдеров экрана. Шире 648 px — `AlertDialog` 520, уже — `Dialog.fullscreen` с `AppBar`. Подпись полосы фокуса — «Работа N%» / «Отвлечения M%» (как в макете). Свёрнутые дети `ExpansionTile` не строятся, поэтому раскладка «По помидорам» видна только после раскрытия. Раскладку по помидорам `showTaskWindowsDialog` передаёт, только если помидоров ≥ 2, свежие сверху. Тестовый флаг платформы — параметр `TaskMenu.isWindows` (`@visibleForTesting`); остальные места (`_BucketRow`, `_DoneRow`) берут `Platform.isWindows`. Второй пункт `_DoneRow` — «Окна всей задачи» (`taskWindows`), «Что было открыто» теперь тоже идёт через общий диалог (с подзаголовком).
