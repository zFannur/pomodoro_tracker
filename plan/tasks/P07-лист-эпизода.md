## 1. `lib/presentation/widgets/cause_chips.dart`

`CauseChips({Cause? selected, ValueChanged<Cause?> onSelected, bool includeFinished = false})` —
`Wrap` из `ChoiceChip` по порядку §4.1; `includeFinished` добавляет «Доделал» последним

`onFinished`). Используется в листе и в «На чём встал?» — один виджет.

## 2. `lib/presentation/widgets/episode_sheet.dart`

```dart
Future<void> showEpisodeSheet(BuildContext context, {
  required EpisodeSource source,
  PomoTask? task,
  Episode? existing,   // дозаполнить тихий эпизод детектора вместо нового
});
```
Ширина < 600 — `showModalBottomSheet(isScrollControlled: true, useSafeArea: true)`,
иначе `Dialog` шириной 460. Содержимое одно. Кубиты читать ДО показа (ленивый builder).

**Шаг 1 «Что мешает?»** — заголовок `S.episodeTitle`, под ним описание задачи
(если есть), `CauseChips`, поле «Мысль (по желанию)» (одна строка), кнопка
`S.episodeJustMark` «Только отметить».
- Тап по причине: эпизод сохраняется сразу (`existing` → `setCause`, иначе
  `addEpisode(..., cause:, thought:)`) — данные не теряются, если лист закроют.
- `external` → сразу шаг 2 с кандидатами для external.
- Если `insight.observation` — вместо шага 2: текст `S.observationNote`
  («Неделя наблюдения: просто отмечаем. Способы — со следующей недели.») и кнопки
  [Готово] / `S.observationHelp` «Всё равно помочь →» (открывает шаг 2).

**Шаг 2 «Попробуй»** — `insight.ranked(cause)`: первый — карточка (заголовок,
текст, действие), строка «Помогало тебе: X из Y», если `tries ≥ 3`; ниже
«Другой способ:» — чипы остальных, тап меняет карточку.
Нажатие на любую кнопку действия: `setStrategy(id, kind, fact:, alt:)`, затем действие,
затем закрыть лист.

Действия по видам (§4.2):

| Вид | Поля | Кнопки → эффект |
|---|---|---|
| firstStep | `FirstStepField` (значение задачи) | «Сохранить и разгон 10 мин» → `setPlan(firstStep)` + `startWarmup(10)` |
| warmup | — | «Разгон 10 мин» → `startWarmup(10)` |
| ifThen | «Когда…», чип времени, «то:» = первый шаг задачи или `FirstStepField`, если пуст | «Сохранить» → `setPlan(cue, cueAt, firstStep)`; «Сохранить и разгон» → + `startWarmup(10)` |
| shrink | «Минимальная версия» | «Добавить и начать» → `addSmaller` + `timer.start()` |
| thought | мысль (из шага 1), «Что я знаю наверняка», «Как сказать точнее»; слот под ✨ (P11) | «Сохранить и разгон 10 мин» |
| defuse | текст `S.defuseLine(мысль)`, если мысль есть | «Разгон 10 мин» |
| value | `why` направления задачи; пусто — поле `S.fieldWhy` (сохранить в направление); нет направления — `S.valueNoDirection` | «Разгон 10 мин»; без направления + «Во „Входящие“» → `postpone(inbox, countDeferral: false)` |
| rest | — | «Отдых 10 мин» → `startRest(10)` |
| removeCue | «Мысль — во „Входящие“» (необязательно) | «Продолжить» → строка в инбокс (`tasks.add(.., toPlanner: true)`), затем `resume()` если пауза, `start()` если стоп |

Если помидор уже идёт (`running`, сигнал distract) — кнопки разгона/старта не
перезапускают таймер: только сохраняют и закрывают (подпись `S.actionContinue`).
Нет задачи (`task == null`) — способы, которым нужна задача (firstStep, ifThen,
shrink), не показывать.

## 3. Таймер

- Подсказка `stuckHint` (простой ≥10 мин): вместо текста — `ActionChip`
  `S.stuckChip` «Застрял? Что мешает начать →» → лист (`idle`, текущая задача,
  `existing: insight.pendingEpisode(idle)`). Только если есть задачи; иначе старый текст.
- Кнопка «Не идёт» в `_buttons`, когда режим pomodoro и таймер `stopped` или `paused`:
  `TextButton.icon(Icons.psychology_alt_outlined, S.notGoing)`; на узком экране
  только иконка с tooltip → лист (`manual`).
- Чип отвлечения: если `insight.pendingEpisode(distract)` не null — над кнопками
  `ActionChip` «Отвлёкся на {app} — отметить причину» → лист (`existing`).
- «На чём встал?»: под полем — `CauseChips(includeFinished: true)` с подписью
  «Почему остановился». При сохранении/пропуске: выбрана причина (не «Доделал») →
  `addEpisode(source: stop, task: текущая, cause:)`. Заметка — как раньше, в заметки
  дня (в эпизод не копировать). Шаг 2 здесь не показывать.

## 4. Переносы

- `HomeShell`: `BlocListener<InsightCubit>` на смену `lastDeferral`: `count ≥ 3` →
  `SnackBar(S.deferralSnack(count) «Перенос №{n}. Разобрать, что мешает?», action: S.deferralAction «Разобрать»)` → лист
  (`defer`, задача по id из `tasks`, `existing`).
- Строки задач (`_TodayRow`, `_BucketRow`): `deferrals ≥ 3` → маленький бейдж `↻N`
  (`labelSmall`, `colorScheme.tertiary`), tooltip `S.deferralsTooltip` «Переносили N раз».
