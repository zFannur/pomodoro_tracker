## 1. Модель содержимого — `lib/app/help_content.dart`

Чистый Dart, без Flutter-импортов (его читает тест-генератор документа).

```dart
enum HelpTarget { timer, tasks, sprint, course, stats, review, reviewEpisodes, reviewWindows,
                  settingsTimer, settingsNotify, settingsApp, settingsAi }

sealed class HelpBlock {}
final class Lead extends HelpBlock { final String text; }
final class Para extends HelpBlock { final String text; }
final class Heading extends HelpBlock { final String text; }
final class Steps extends HelpBlock { final List<({String where, String what})> items; }
final class Bullets extends HelpBlock { final List<({String term, String text})> items; } // term может быть ''
final class Compare extends HelpBlock { final List<({String bad, String good})> items; }
final class Tip extends HelpBlock { final String text; }
final class Warn extends HelpBlock { final String text; }
final class Go extends HelpBlock { final String label; final HelpTarget target; }
final class PathBlock extends HelpBlock {}
final class Sources extends HelpBlock {}

class HelpSection { final String id; final String emoji; final String title; final List<HelpBlock> blocks; }

List<HelpSection> helpSections();                 // по S.lang: _ru или _en
List<HelpStage> adoptionStages();                 // этапы и шаги пути (по S.lang)
List<({String title, String url})> helpSources();
```
`HelpStage { String title; String hint; List<HelpStep> steps; }`,
`HelpStep { String id; String title; String where; bool optional; bool windowsOnly; HelpTarget? target; }`.

Перенеси текст из `СПРАВКА.md` **дословно** (`_ru`) и переведи на английский (`_en`) в
том же порядке. Инлайн-разметка в строках: только `**жирный**` и `` `код` `` —
рендерер понимает эти две.

## 2. Отметки пути — `lib/domain/adoption.dart`

```dart
/// Снимок данных, по которым пути видно выполнение шагов. Собирается в UI
/// из кубитов, чтобы функция осталась чистой и тестируемой.
class AdoptionFacts { … }   // поля по таблице «Путь внедрения» в СПРАВКА.md
bool stepDone(String stepId, AdoptionFacts f, Set<String> manualChecks);
int currentStage(List<HelpStage> stages, AdoptionFacts f, Set<String> manual, {required bool windows});
/// «3 из 5», «4 утра из 7» — для шагов с порогом-числом; null для остальных.
String? stepProgress(String stepId, AdoptionFacts f);
```
Правила — столбец «Отмечается» таблицы, буквально. «вручную» → `manualChecks.contains(id)`.
Текущий этап — первый, где не выполнен хотя бы один обязательный шаг (необязательные и
`windowsOnly` на не-Windows не учитываются). Все выполнены → `stages.length` (путь пройден).

Ручные отметки — `AppSettings.helpChecks` (`List<String>`, локально). Флаг первого
показа — `AppSettings.helpSeen` (int, версия справки; сейчас 1).

## 3. Окно — `lib/presentation/screens/help_screen.dart`

```dart
Future<void> showHelp(BuildContext context, {String section = 'start'});
```

**Широкий экран (≥ 900):** `Dialog` 960×680 (не больше 92% окна), внутри `Row`:
- **Меню слева, 260 px**: поле поиска сверху; список разделов (эмодзи + заголовок,
  выбранный — фон `secondaryContainer`, скруглённый); внизу — мини-прогресс пути
  «Внедрение · этап 2 из 5» с `LinearProgressIndicator`.
- **Содержимое справа**: заголовок раздела крупно, ниже блоки, ширина текста ≤ 640,
  прокрутка; внизу раздела — «← Предыдущий / Следующий →».
- Крестик в правом верхнем углу; `Esc` закрывает.

**Узкий экран:** полноэкранный маршрут: список разделов карточками (с прогрессом пути
первой карточкой) → тап открывает раздел (`Navigator.push`), назад — к списку.

**Поиск:** фильтрует меню по вхождению запроса (без регистра) в заголовок и тексты
блоков раздела (у раздела с `PathBlock` — ещё заголовки и «где» шагов пути); в найденном разделе совпадения подсвечиваются (`TextSpan` с фоном
`tertiaryContainer`). Пустой результат — «Ничего не нашлось».

**Блоки** (по одному приватному виджету на тип):

| Блок | Вид |
|---|---|
| Lead | `titleMedium`, `onSurfaceVariant`, отступ снизу 16 |
| Para | `bodyMedium`, межстрочный 1.5 |
| Heading | `titleSmall` жирный, отступ сверху 20 |
| Steps | карточки с номером в круге `primary`, «где» жирным, «что» — обычным |
| Bullets | термин жирным, текст рядом; без термина — обычная точка |
| Compare | две колонки: «✗ …» на `errorContainer` 40% / «✓ …» на `primaryContainer` 40%; на узком — друг под другом |
| Tip / Warn | плашка с иконкой `lightbulb_outline` / `warning_amber`, скругление 12 |
| Go | `FilledButton.tonal` со стрелкой → `_go(target)`: закрыть справку и открыть место |
| PathBlock | см. ниже |
| Sources | список ссылок, тап → `launchUrl` |

**Путь внедрения (PathBlock):**
- Сверху — плашка «Следующий шаг: {первый невыполненный шаг текущего этапа}» + кнопка
  перехода (если у шага есть `target`).
- Этапы — вертикальный степпер: круг с номером (выполненный — ✓ на `primary`),
  заголовок, счётчик «3 / 6», подсказка этапа. Выполненные этапы свёрнуты, текущий
  развёрнут, будущие — развёрнуты, но приглушены (opacity 0.55).
- Шаг: иконка состояния (выполнен сам — `check_circle` `primary`; ручной — `Checkbox`,
  отметка пишет `helpChecks`; не выполнен — `radio_button_unchecked`), заголовок,
  строка «где» серым, метка «по желанию» для `optional`, справа — «Открыть» (если `target`).
- Факты (`AdoptionFacts`) собираются из `DirectionsCubit`, `TasksCubit`, `InsightCubit`,
  `ActivityCubit` (если есть), `SettingsCubit` при открытии и при каждом их изменении
  (`context.watch`).

**Переходы `_go(target)`:** вкладки — `homeTab.value = индекс`; `reviewEpisodes`/`reviewWindows` —
вкладка «Разбор» + индекс подвкладки (добавь в `InsightScreen` `ValueNotifier<int> insightSubTab`
рядом с `homeTab`); настройки — `showSettingsDialog(context, initialTab: …)` (добавь параметр).

## 4. Где открывается

- **Широкий экран:** иконка `help_outline` в `NavigationRail.trailing` над шестерёнкой,
  tooltip «Справка (F1)».
- **Узкий:** `IconButton(help_outline)` в `AppBar.actions` перед шестерёнкой.
- **F1** — глобально, как `Ctrl+N` (посмотри, как сделан его обработчик), не в
  полях ввода.
- **Первый запуск после обновления:** `helpSeen < 1` → после первого кадра открыть на
  разделе `start`, затем `helpSeen = 1`. Не в тестах (флаг через настройки фейка).
- **Контекстные «?»** (маленькая `IconButton(help_outline, size: 18)`), одна на место:
  заголовок листа эпизода → `stuck`; «Разбор → Неделя» → `review`; «Разбор → Окна» и
  диалог окон → `windows`; вкладка настроек «ИИ» → `ai`; заголовок «Курса» → `levels`.
