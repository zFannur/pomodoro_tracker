## 2. `lib/presentation/screens/insight_screen.dart`

`DefaultTabController`: «Неделя» / «Эпизоды» / «Окна». «Окна» — существующий
`ActivityScreen()` как есть, только на Windows (флаг `showWindows` в конструкторе,
по умолчанию `Platform.isWindows` — для тестов).

### 2.1 Неделя

Колонка, `maxWidth: 720`, по центру, `ListView`. Сверху вниз:

1. **Заголовок**: «Неделя {W45}» + «· неделя наблюдения», если `observation`.
2. **Плитки** (общий виджет плитки: если `_StatGrid` в `stats_screen.dart` годится —
   вынеси плитку в `widgets/common.dart` и используй в обоих местах; не копируй):
   «Первый помидор» (лаг «+25 мин» или время «10:40»), «Простой» «8 мин», «🐸 первой» «4/6»,
   «Переносы» «3», на Windows «Отвлечения» «12%». Под значением — Δ к прошлой неделе
   стрелкой: цвет `primary`, если лучше (`lowerIsBetter`), `error`, если хуже; и «база: X»
   мелко. null → «—» и подсказка «мало данных».
3. **Причины**: строки «Непонятно, с чего начать ███████ 7 · лучше всего: Первый шаг 4/5».
   `external` — отдельной серой строкой «Отвлекали: 3» в конце (не избегание).
   Нет эпизодов — «Пока нет отметок. Сигналы появятся сами, когда таймер стоит, а задачи есть.»
4. **Самочувствие → дела**: для `sleep` и `energy` × (`idle`, `frogFirst`) — строки
   вида «Сон ≥4: простой 6 мин · сон ≤2: 18 мин». Все null — одна строка «Отмечай сон утром —
   через 3–4 недели здесь появится связь».
5. **Эксперимент**:
   - Прошлой недели без вердикта → карточка «Итог: {гипотеза}. Было X → стало Y» +
     `SegmentedButton` [Работает][Без разницы][Хуже], предвыбран `verdictFor` (unclear —
     ничего не выбрано, подпись «мало данных»). Выбор → `setVerdict(prevId, v)`.
   - Текущий есть → «{гипотеза} · {метрика}: было X → сейчас Y · осталось N дн.» и
     «Снять» → `clearExperiment`.
   - Текущего нет → карточка-предложение: `review?.experiment` (P11) или
     `suggestExperiment(...)` → [Взять] [Свой…] [Не сейчас]. «Свой…» — диалог: гипотеза,
     выпадающий список способа, выпадающий список метрики (подписи из `S`).
     «Не сейчас» скрывает предложение до следующего открытия экрана.
6. **Слот ИИ**: `Widget? aiSlot` — P11 вставит кнопку и карточку. Сейчас: если
   `sprint.review` есть — показать summary и закономерности; иначе ничего.
7. **Шкала**: если в текущем месяце нет дня с `ips` и `day ≤ 7` → карточка
   «Шкала откладывания · 9 вопросов, 1 минута» [Пройти]. Ниже, если ≥2 результата, —
   строка истории «авг 31 · сен 29 · окт 27» (сумма баллов, меньше — лучше).

### 2.2 Эпизоды

Последние 14 дней, группы по дням (заголовок «Сегодня» / «Вт, 3 ноября»). Строка:
время · иконка источника · задача · чип причины (нет — «—», тап → `showEpisodeSheet(existing:)`)
· способ · ✓/✗ (`episodeSucceeded` по сессиям дня; без способа — пусто).
Меню строки: «Удалить» → `deleteEpisode` + снекбар без отмены. Сверху — фильтр чипами
по причине (повторный тап снимает).

Иконки источников: idle `hourglass_empty`, stop `stop_circle_outlined`, defer `redo`,
frog — текст «🐸», distract `open_in_new`, manual `psychology_alt_outlined`.

## 3. Шкала IPS — `lib/presentation/widgets/ips_dialog.dart`

9 утверждений, у каждого 5 вариантов (1 «совсем не про меня» … 5 «точно про меня»),
кнопка «Сохранить» активна, когда отвечены все → `insight.saveIps(answers)`.
Сумма для истории — с учётом обратных пунктов. **Тексты пунктов и номера обратных
пунктов** возьми из Svartdal & Steel 2017, «Irrational Delay Revisited»,
Frontiers in Psychology 8:1927 (открытый доступ, CC BY 4.0): английский — дословно,
русский — свой перевод, в `strings.dart` пометь комментарием «неофициальный перевод,
не валидирован». Не можешь открыть источник — остановись и сообщи, не выдумывай пункты.

## 4. Спринт

Под вехой — маленькая карточка, только если есть `insight.experiment`:
«🧪 {гипотеза} · {метрика}: было X → сейчас Y». Тап → `homeTab.value = kInsightTab`.
